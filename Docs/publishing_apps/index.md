# Publishing your apps

## Export your app

1. Go to the Administration > Metamodel > Apps, select your app and press "Export model" button
2. Open the IDE for that app to check the exported files
3. If you want to use placeholders in your docs or need SQL migrations, you need to wire up some installers, that will run every time you export or import your app model - see [../developer_docs/App_installers/index.md](../developer_docs/App_installers/index.md) for more information.
