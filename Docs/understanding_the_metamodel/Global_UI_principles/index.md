# Global UI principles

The user interface is generated by a UI facade by translating model components like pages and widgets into JS code. The entry point is always a page. The look&feel changes from facade to facade (as well as the underlying UI framework), but the global principles described in this chapter remain. 

## UI structure

The entire UI is structured in **screens**. A screen is what an end user 
recognizes as a "place" in the app. Technically screens are the result of rendering a `Page`, a `Dialog` or a `Popup` widget. 

A screen consists of the surrounding launcher UI (global header and footer, main menu, context bar, etc.) and the the rendered widgets in its main work area. 

### UI model components

- UI page - item of the main menu. Pages have their own URLs and are the entry points to the UI. 
- Main menu - tree structure of pages. Typically shown as a collapsible side-panel. Apps will mostly provide one or two root nodes to the menu with all their pages inside. Users often see only part of the menu as restrictions via policies for the UI page authorization point are very common. 
- Widgets are what the UI inside pages is built from. Every page has one root container widget with other widgets inside. 
- Some widgets represent separate screens by themselves - e.g. `Dialog` or `Popup`. These widgets are mostly defined inside actions, that are called by `Button` widgets in a page. 
- Navigation actions like `ShowDialog`,  `GoToPage`, `GoBack`, etc. switch between screens. 
- Default editors are pre-configured widget models for entire objects. They are rendered by actions like `ShowObjectEditDialog`, `ShowObjectCreateDialog` or within the special `ObjectEditor` widget.
- The `ContextBar` is a special widget, that is part of the launcher. It lets users interact with long-living contexts - much like the windows tray. Each context provides an icon for the bar, which opens a menu to interact with thus context.

## UI facades

Facades take care of rendering the UI model in HTML and Javascript. Different facades use different UI frameworks and implement different design systems.
